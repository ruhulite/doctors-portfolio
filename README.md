# Gastroenterologist Portfolio

React + Vite + TypeScript + Tailwind CSS v4 starter for Professor Dr. Muhammad Abdullahel Kafi.

## Setup
1. Install Node.js 20.19+ (or a compatible current LTS).
2. Run `npm install`.
3. Run `npm run dev`.
4. Run `npm run typecheck` and `npm run build` before deployment.

## Structure
- `src/app`: route configuration
- `src/components/layout`: shared header, footer and site shell
- `src/components/ui`: reusable primitives
- `src/components/sections`: reusable page sections
- `src/pages`: route-level pages
- `src/i18n`: English and Bangla translations

## Notes
- The appointment form is front-end only and does not transmit or store data.
- IBN Sina branch address and contact number are placeholders pending confirmation.
- Replace the portrait placeholder with an approved doctor photograph.
- Verify credentials, experience, chamber schedule and contact information before launch.
- Backend integration, admin approval workflow, persistent booking, slot locking and notifications are not included yet.
